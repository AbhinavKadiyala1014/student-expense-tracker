
# SpendWise — Student Expense Tracker

A responsive expense tracker website built to help students manage their monthly budgets and expenses.

## Features

- Set a personal monthly budget
- Track total expenses and remaining balance
- Add and delete transactions
- Organize expenses by category
- View spending charts
- Filter transactions by month and category
- Save data in browser storage
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Local Storage

## How to Run

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Enter your budget and start tracking expenses.

An internet connection is needed to load Chart.js.

## Project Structure

- `index.html` — Website structure
- `style.css` — Website design
- `script.js` — Expense tracking functionality
- `README.md` — Project documentation

## Data and Privacy

The app stores expenses and the budget in your browser. Data does not automatically synchronize across devices.
