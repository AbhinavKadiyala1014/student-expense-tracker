# 💰 SpendWise — Student Expense Tracker

**Track your spending. Manage your budget. Build better money habits.**

SpendWise is a responsive expense tracker website designed to help students manage their monthly budgets, track daily expenses, and understand their spending habits through an easy-to-use interface.

## ✨ Features

- 💵 **Monthly Budget** — Set a personal budget for the month.
- 📊 **Expense Overview** — Track total expenses and remaining balance.
- ➕ **Transaction Management** — Add and delete expense transactions.
- 🗂️ **Category Management** — Organize expenses by category.
- 📈 **Spending Charts** — Visualize expenses using Chart.js.
- 📅 **Monthly Filters** — Filter transactions by month and category.
- 💾 **Local Data Storage** — Save your budget and transactions in browser storage.
- 📱 **Responsive Design** — Use the website on desktop and mobile devices.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- An internet connection to load Chart.js

### Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Set your monthly budget.
5. Start adding and managing your expenses.

## 🔐 Data and Privacy

SpendWise stores the budget and expense data in your browser using Local Storage.

- Data is stored locally in the browser.
- Data does not automatically synchronize across devices.
- Clearing browser data may remove saved expenses and budget information.
- The application does not currently provide cloud synchronization.
